# UI 黑盒回归计划（Round 37）

日期：2026-11-14  
范围：项目应用布局反馈修复

## 目标

验证“展开/收起”操作会在页面中产生稳定、可见、可回放的布局状态反馈，并且不改变应用实例、会话或运行上下文。

## 用例

| 编号 | 页面操作 | 预期 |
| --- | --- | --- |
| R37-01 | 在应用实例运行但尚未打开内嵌视图时点击“展开” | 页面显示布局状态为“展开”或等价明确反馈 |
| R37-02 | 同一状态点击“收起” | 页面显示布局状态恢复为“侧栏”或等价明确反馈 |
| R37-03 | 打开内嵌应用后分别点击“展开”和“收起” | 内嵌视图和页面状态均同步变化 |
| R37-04 | 切换应用面板、运行上下文和项目会话 | 布局状态不丢失，应用实例和轨迹不串线 |

## 判定规则

- 只用 Electron 页面实际可见文字、按钮状态和视图变化判定。
- “调用成功”但页面没有变化不算通过。
- 本轮不修改代码；发现问题时先完成整轮并记录，再进入下一轮修复。
