# Electron 页面回归计划（Round94）

日期：2026-11-15

本轮目标：验证项目内可逆文件生命周期，覆盖写入、读取验证和删除清理。

## 用例

| ID | 场景 | 操作 | 预期 |
|---|---|---|---|
| W01 | 写入临时文件 | 创建项目根目录 `.__capybara_ui_round94__.txt`，写入固定内容 `round94-ok` | 页面显示 `write_file` 成功收据、路径和结果。 |
| W02 | 读取验证 | 读取该临时文件 | 页面显示 `read_file` 成功，内容与固定值一致。 |
| W03 | 删除清理 | 删除该临时文件 | 页面显示 `delete_file` 成功；任务结束后临时文件不应继续存在。 |
| W04 | 会话恢复 | 清理完成后发送“只回复 OK，不调用工具” | 后续请求正常完成，前面三步仍可回放。 |

## 通过标准

- 只通过页面发起和观察工具调用；不使用 shell 代替产品能力。
- 每个工具步骤记录工具名、参数、状态、耗时、错误和结果 artifact。
- 任务结束后确认页面没有残留临时文件证据为“存在”。
- 本轮先完整测试，发现问题后再决定是否修复，不边测边改。
