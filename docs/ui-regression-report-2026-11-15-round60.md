# Capybara V2 页面回归报告（Round60）

## 结论

本轮在最新 Electron 构建上复测视图、工具、应用视图、主题、侧栏、帮助和设置。项目应用菜单切换已经修复并通过；应用展开、内嵌浏览器打开/关闭、主题和侧栏均有可见反馈。工具菜单的入口可以被点击，但部分条目仍复用运行上下文或显示保留提示，项目资源入口实际打开的是项目设置与资源面板，动作语义尚未完全拆开。没有发现新的 P0/P1 运行阻塞。

## 新增或确认的缺口

1. 工具菜单的动作矩阵仍未完全闭环：多个不同名称的入口共享运行上下文，三个入口仍是保留状态。
2. “项目资源”与“设置”都落到同一项目控制面，资源治理、模型配置、变量和 Skill 安装尚未在导航和页面语义上分层。
3. “定时与触发”“能力演化”“Token 用量”“项目文件”“导出项目快照”仍需要真实页面或完整产物闭环，当前只能证明入口有反馈。
4. 运行上下文可以打开并显示当前 Runtime、进程、子智能体和证据计数，但空会话仍只有摘要状态；真实运行时的逐步事件回放需要继续用实际任务补证。

## 阶段判断

Round60 证明上一轮发现的“视图→项目应用无法切换”已修复，项目应用和内嵌浏览器的页面控制达到可继续施工水平。当前剩余问题集中在菜单动作语义、资源治理页面分层和调度/用量等产品功能，不构成核心桌面运行阻塞。
