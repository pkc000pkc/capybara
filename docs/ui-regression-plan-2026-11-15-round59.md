# Capybara V2 页面回归计划（Round59）

## 目的

在 Round58 确认运行上下文、项目应用、浏览器入口和项目隔离后，补齐菜单命令和高频控制入口的页面动作验证。本轮只做页面黑盒操作，不修改代码；发现问题先记录，整轮结束后再集中修复。

## 用例

| 编号 | 页面动作 | 通过标准 |
|---|---|---|
| R59-01 | 文件菜单依次点击“新会话”“打开项目并取消”“项目文件”“导出项目快照” | 每个动作都产生可见反馈；新会话只创建一条；取消不改变当前项目；项目文件和快照入口不得静默无响应。 |
| R59-02 | 视图菜单依次切换“项目侧栏”“项目应用”“深色外观”，再恢复原状态 | 侧栏、应用面板和外观都有可见变化；恢复后项目、会话和应用状态不丢失。 |
| R59-03 | 工具菜单逐项点击“定时与触发”“协作任务”“进程管理”“项目资源”“能力演化”“本地运行与恢复”“Token 用量”“设置” | 每个入口打开对应面板、对话框或明确状态；不得出现点击后无变化。 |
| R59-04 | 帮助菜单点击“关于概念稿”，检查内容和关闭按钮 | 关于窗口可见，内容与当前产品定位一致，关闭后回到工作区。 |
| R59-05 | 在研究项目的项目应用面板点击“展开”“收起”“打开应用”“关闭应用视图” | 布局状态和嵌入视图状态同步变化；主工作区不被遮挡；关闭后应用面板仍可恢复。 |
| R59-06 | 打开项目设置，检查模型配置、提示词变量、Skill、插件和已安装资源区域，关闭设置 | 设置页无读取错误；全局密钥只显示配置状态；项目/系统资源来源清晰；关闭后项目应用和会话状态保持。 |

## 记录要求

- 每个用例记录初始页面、点击顺序、按钮文案、可见反馈、最终状态和是否产生新消息。
- 只使用当前 Electron 页面和原生对话框；不以代码搜索或自动化测试替代页面证据。
- 本轮不执行会改变项目文件或安装外部资源的动作；仅观察预览、入口和状态表达。
- 完成本轮全部用例后，先写报告，再决定是否修复局部前端或状态逻辑。
