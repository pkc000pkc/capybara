| 用例 | 结果 | 观察 |
| --- | --- | --- |
| R71-01 | 通过 | 最新构建打开 Example Domain，浏览器顶栏控件和地址正常。 |

| R71-06 | 部分通过 | 浏览器会话打开时，项目应用按钮没有呈现行情看板视图，两个宿主视图存在覆盖/焦点竞争。需要在两个视图之间增加互斥切换。 |

## 后续修复项

1. 浏览器会话打开项目应用时，先关闭通用浏览器会话；打开通用浏览器时，先关闭项目应用视图，避免两个 WebContentsView 争用同一侧栏。
2. 同一个浏览器会话重复打开时不重复追加聊天摘要。

本轮确认 Round70 的地址复用缺陷已修复；剩余问题是两个宿主视图的显示互斥和重复摘要。
