# Electron 页面回归计划（Round81）

日期：2026-11-15

本轮目标：验证 Round80 发现的问题修复，不扩大测试范围，不在页面操作过程中修改代码。

## 用例

| ID | 场景 | 操作 | 预期 |
|---|---|---|---|
| F01 | 无启动命令的空白项目 | 打开没有 `start` 命令的项目，进入项目应用并点击启动 | 不出现 `Error invoking remote method` 或原始 IPC 文本；显示“未配置应用启动命令”及可理解的下一步；应用仍为已停止 |
| F02 | 项目切换清空运行上下文 | 在有历史 Trace/进程/治理记录的项目打开运行上下文，切换到另一个项目 | 切换瞬间运行上下文进入空/恢复状态；新项目 Snapshot 到达后只显示新项目的时间线、进程、候选、证据和治理记录 |
| F03 | 已发布应用回归 | 切回已有已发布应用的项目，打开项目应用 | 研究结果、产物、应用状态和运行入口恢复；不显示空白项目的错误 |
| F04 | 聊天回归 | 在当前项目新会话发送一次只读短指令 | 用户消息只出现一次，回复完成，执行过程可展开 |

## 通过标准

- F01 的错误提示不包含 `capybara:application-start`、`remote method` 等内部实现细节。
- F02 在新快照到达后没有旧项目的 `turnId`、`callId`、进程、候选或治理记录。
- F03/F04 不引入 Round80 已通过功能的回归。
- 页面操作结束后写入 `docs/ui-regression-report-2026-11-15-round81.md`，再决定是否需要下一轮修复。
