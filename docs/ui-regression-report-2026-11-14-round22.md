# UI 回归报告（2026-11-14 · Round 22）

本轮复测停止/重启时的内嵌视图收束。测试使用重新构建的 Electron 页面和 `qingjian-generated` 项目。

## 结果

| 用例 | 结果 | 页面观察 |
|---|---|---|
| R22-01 启动应用 | **通过** | 面板显示运行中、实际地址、PID、端口和 healthy。 |
| R22-02 视图打开后直接停止 | **未通过，入口不可操作** | 内嵌 `WebContentsView` 覆盖了右侧应用面板，点击面板中的“停止”无法触发停止；视图仍然打开、实例仍显示运行中。必须先使用顶部“关闭应用视图”恢复工作台，再点击面板停止。 |
| R22-03 重启收束 | 未执行 | 依赖 R22-02 能从内嵌视图直接触发停止。 |

## 新缺陷

### P1：内嵌应用覆盖项目应用控制区

当前内嵌视图覆盖了右侧项目应用面板，导致启动后的停止、重启、更新等控制无法直接点击。顶部只有“关闭应用视图”，用户必须先关闭视图才能控制实例，实例管理和视图管理被迫分成两个动作。

## 修复方向

在始终位于 Workbench 顶部的菜单栏提供“停止应用”入口；该入口应调用同一套 Runtime/主进程停止流程，并在停止成功后关闭 `WebContentsView`。这样应用视图保持全屏显示时，用户仍能停止托管进程。
