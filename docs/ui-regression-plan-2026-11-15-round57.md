# Capybara V2 页面回归计划（Round57）

## 目的

验证市场研究结果写入项目级 `.capybara` 存储后，项目切换、关闭重开和桌面重启均能恢复同一项目的结果，并且空项目不会显示其他项目的数据。

## 用例

| 编号 | 页面动作 | 通过标准 |
|---|---|---|
| R57-01 | 启动最新构建，在研究项目打开项目应用并运行市场研究 | 研究完成后显示研究卡片、步骤和看板入口；结果写入当前项目。 |
| R57-02 | 切换到空项目，再切回研究项目 | 空项目不显示研究卡片；切回后从项目存储恢复研究结果。 |
| R57-03 | 关闭研究项目，再从“打开本地项目”重新打开 | 研究结果仍存在，且结果与项目名称、看板入口一致。 |
| R57-04 | 关闭 Electron，使用标准命令重新启动并打开研究项目 | 研究结果仍能恢复；页面不依赖 renderer localStorage。 |

## 记录要求

- 只通过 Electron 页面和原生项目选择器操作。
- 记录每个用例的项目名称、研究状态、结果卡片和应用页签。
- 本轮只验证已完成实现，不在页面操作过程中修改代码。
