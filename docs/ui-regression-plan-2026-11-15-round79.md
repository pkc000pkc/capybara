# Electron 页面回归计划（Round79）

日期：2026-11-15

## 目的

验证 Runtime 快照主动恢复浏览器 View，以及项目应用资料来源页的文件复核入口。

## 页面用例

1. 启动最新 Workbench，打开已有浏览器 Runtime 轨迹的项目，确认 Runtime 连接后浏览器工具栏自动恢复，不需要先发送新的 Agent 指令。
2. 确认恢复后的 URL、项目归属和浏览器状态可见；恢复失败时显示需要验证的错误，而不是伪装成已连接。
3. 打开项目应用的“资料来源”，确认 quarantine Artifact 显示“复核 / 接受 / 拒绝”。
4. 点击“复核”后确认状态和结果提示发生变化；不执行接受或拒绝，避免改变现有测试数据。

## 通过标准

- Runtime 快照带来的浏览器上下文会自动创建受控 WebContentsView。
- UI 浏览器会话和 Runtime 浏览器动作使用同一项目身份，不触发跨项目错误。
- 资料来源页可以触发后端文件存在性/哈希校验并反馈结果。

## 约束

- 本轮只进行页面观察和交互，不在 UI 操作期间修改代码。
- 接受/拒绝按钮只验证可见性，不提交状态变更。
