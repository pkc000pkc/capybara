# Capybara V2 页面回归计划（Round66，2026-11-15）

## 目的

补齐剩余控制入口的页面证据，覆盖运行上下文页签、项目应用面板与宿主能力按钮、内嵌视图开关、历史会话和窗口导航状态。

## 用例

| 编号 | 页面动作 | 通过标准 |
|---|---|---|
| R66-01 | 打开运行上下文，依次点击时间线、进程、子智能体、证据治理 | 每个页签切换后内容区域与标题/计数对应，空状态或收据列表清晰可见。 |
| R66-02 | 项目应用面板关闭/恢复，切换总览、内容与数据、资料来源 | 面板关闭后主区恢复，重新打开后应用数据不丢失，三个页签可切换。 |
| R66-03 | 点击浏览器网关和市场研究能力入口 | 能显示可观察的能力状态、读取结果或明确错误，不出现无响应。 |
| R66-04 | 打开已发布应用、查看内嵌页面、关闭应用视图 | 内嵌页面内容可见；关闭后回到工作台，应用地址和发布状态保持。 |
| R66-05 | 切换历史会话并返回当前会话 | 会话标题、消息和请求计数对应切换；项目应用状态不串入其他项目。 |
| R66-06 | 检查后退/前进导航按钮在无历史和有历史时的禁用/可用状态 | 无历史时禁用；产生导航历史后可回退并能前进恢复。 |
| R66-07 | 打开设置并关闭，不修改敏感配置 | 设置面板能读取全局模型状态、密钥隐藏和资源列表，关闭后工作区保持。 |

## 记录要求

- 使用最新 `apps/workbench/out` 构建和标准 Electron 启动。
- 每次点击前记录预期，点击后读取最新页面状态。
- 本轮只做页面验证；完成整轮并写报告后再决定是否修复发现的问题。
