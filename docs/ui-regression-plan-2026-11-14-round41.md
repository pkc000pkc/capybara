# UI 黑盒回归计划（Round 41）

日期：2026-11-14  
范围：有效资源安装、项目/系统资源隔离、错误状态生命周期和运行上下文详情

## 目标

验证资源治理从“非法输入能报错”推进到“有效资源能预览/安装、项目边界不串、错误状态不会冒充当前成功状态”；同时确认运行上下文的治理页签和详情展开仍能回放现有任务。

## 用例

| 编号 | 页面操作 | 预期 |
| --- | --- | --- |
| R41-01 | 切换到空的 `ui-regression-clean-2026-11-14` 项目，打开设置 | 项目资源为空或仅显示系统回退资源；当前项目的配置、会话和应用状态与 `qingjian-generated` 隔离 |
| R41-02 | 输入有效 GitHub Skill：`openai/skills` + `skills/.curated/openai-docs`，点击预览 | 显示完整 commit、Skill 名称、文件列表和安全提示；安装按钮变为可用 |
| R41-03 | 点击安装 Skill | 页面显示安装成功并刷新目录 revision/已安装资源；不得误报失败或把资源写入系统目录 |
| R41-04 | 切回 `qingjian-generated`，重新打开设置 | 空项目中新装的 Skill 不出现在原项目；原项目的 000682 研究、应用和资源列表保持 |
| R41-05 | 打开运行上下文，切换证据治理/进程页签并展开一条详情 | 页签内容可切换；候选、证据或 receipt 详情可展开，保留调用关联和回放数据 |
| R41-06 | 重新触发一次已知非法插件操作后关闭/重开设置 | 错误应标识为当前请求或历史记录，不应伪装成资源读取失败，也不应清除已有成功资源 |

## 判定规则

- 所有安装和切换动作只通过 Electron 页面完成。
- 先完成整轮操作和记录，再决定是否修复代码；本轮不在测试中修改实现。
- 安装成功必须同时由页面资源列表、目录 revision 和项目切换隔离状态支持。
