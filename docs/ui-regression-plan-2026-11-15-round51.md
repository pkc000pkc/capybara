# UI 黑盒回归计划（Round 51）

日期：2026-11-15  
范围：当前 Electron Workbench 的完整可点击入口、项目/会话切换、设置与资源、运行上下文、项目应用、菜单和输入发送。

本轮严格先点后修：执行期间不修改实现；每个用例先完成页面动作，再记录可见结果、状态变化和错误。若发现问题，只记录到报告，回归结束后再进入修复轮。

## 用例

| 编号 | 场景 | 操作 | 通过标准 |
| --- | --- | --- | --- |
| R51-01 | 窗口与主菜单 | 依次打开文件、视图、工具、帮助菜单，再关闭；点击帮助 → 关于概念稿并关闭 | 菜单唯一、不重复、不残留；弹窗有标题、内容和关闭动作 |
| R51-02 | 项目入口 | 点击打开本地项目，选择已登记项目；展开/收起项目侧栏；搜索项目或会话 | 项目切换后名称、会话和状态一致；搜索只过滤当前列表；无旧项目内容串入 |
| R51-03 | 会话入口 | 点击新会话；切换已有会话；连续点击新会话按钮两次 | 只创建一个新会话；会话记录可加载；当前会话标题和消息不串线 |
| R51-04 | 输入与发送 | 输入普通文本并发送；再用 Ctrl+Enter 发送一条文本；观察发送按钮、进度和回复 | 每次只产生一条用户消息；显示运行阶段、工具/模型过程和最终回复；无重复输入框或重复消息 |
| R51-05 | 运行上下文 | 打开“执行过程/查看运行上下文”，依次查看时间线、进程、子智能体、证据治理，再关闭重开 | 页签可切换；计数、工具调用、状态和证据可见；重开后轨迹保持 |
| R51-06 | 项目应用 | 打开项目应用；查看总览、运行安排、内容与数据、资料来源；打开/关闭应用视图；切换侧栏/展开 | 面板和应用视图可打开关闭；状态区分运行实例、发布内容和嵌入视图；布局切换有反馈 |
| R51-07 | 设置与资源 | 打开工具 → 设置；检查模型、密钥状态、变量、Skill/插件目录；关闭再重开 | 设置可读；密钥只显示配置状态；资源来源、revision 和错误状态明确；关闭重开不丢失 |
| R51-08 | 文件与工具保留入口 | 点击项目文件、导出项目快照、定时与触发、能力演化、Token 用量 | 每个按钮都有真实页面、明确空状态或保留入口反馈；不出现底层 IPC 错误 |
| R51-09 | 项目关闭与恢复 | 通过项目菜单关闭当前项目，再重新打开同一项目；重开运行上下文 | 关闭后项目从当前列表移除但磁盘不受影响；重新打开后会话、上下文和应用状态可恢复 |

## 记录要求

- 每个用例记录通过、失败或阻塞，并保存页面可见文字和入口。
- 记录任何 `Error invoking remote method`、空白区域、重复消息、旧项目数据串入或状态矛盾。
- 本轮完成后生成报告，再单独决定是否进入修复轮；不得在点击过程中修改实现。
