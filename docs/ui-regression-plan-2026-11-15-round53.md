# UI 黑盒回归计划（Round 53）

日期：2026-11-15

本轮只通过 Electron Workbench 页面、原生菜单和辅助功能树操作；本轮执行期间不修改实现。完成一轮观察后，才进入修复阶段。

## 用例

| 编号 | 场景 | 操作 | 通过标准 |
|---|---|---|---|
| R53-01 | 单次发送 | 在当前会话输入一条短消息，点击发送或使用 Ctrl+Enter | 页面只新增一条用户消息；运行中显示阶段摘要；完成后只新增一条 Agent 回复；发送按钮和输入区状态正确 |
| R53-02 | 保存会话回放 | 选择已有会话，等待恢复完成，打开“运行上下文” | 聊天记录、时间线、进程、子智能体、证据治理计数属于同一会话；不出现重复消息或跨项目内容 |
| R53-03 | 项目关闭与重开 | 通过项目菜单关闭当前项目，再从已打开项目列表重新打开 | 关闭后当前项目从工作区消失；重开后项目、会话和运行上下文恢复；旧 Runtime 不重复创建 |
| R53-04 | 侧栏折叠与恢复 | 通过视图菜单折叠项目侧栏，再点击页面内恢复入口 | 折叠和恢复均可重复命中；恢复后项目、会话、新会话和打开项目按钮可见 |
| R53-05 | 项目应用状态 | 打开项目应用面板，切换总览/行程安排/资料来源，再关闭 | 三个页签都有内容或明确空状态；关闭后工作区和输入区仍可用；应用状态不串项目 |
| R53-06 | 设置与资源来源 | 打开设置，检查模型配置、变量、工具/Skill/Harness 来源 | 全局配置可见；项目资源与系统回退来源不混淆；关闭设置后回到原会话 |
