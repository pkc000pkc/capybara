# UI 黑盒回归计划（Round 50）

日期：2026-11-14  
范围：帮助菜单、文件菜单剩余入口、工具菜单剩余入口，以及菜单关闭后的工作区稳定性

本轮只做页面点按和结果观察，不在执行期间修改代码。每个用例先完成动作，再记录页面可见结果和状态变化。

## 用例

| 编号 | 场景 | 操作 | 通过标准 |
| --- | --- | --- | --- |
| R50-01 | 关于概念稿 | 打开“帮助”菜单，点击“关于概念稿”，查看弹窗内容，再关闭 | 出现带标题、说明文字和关闭按钮的模态框；关闭后回到原工作区 |
| R50-02 | 文件菜单剩余入口 | 依次点击“项目文件”“导出项目快照”，观察反馈 | 每个入口都有可观察页面结果、状态反馈或明确的禁用/空状态；无 IPC 错误 |
| R50-03 | 工具菜单剩余入口 | 依次点击“定时与触发”“能力演化”“Token 用量”，观察反馈 | 每个入口都有可观察页面结果、状态反馈或明确的禁用/空状态；无 IPC 错误 |
| R50-04 | 菜单交互稳定性 | 在打开、关闭多个菜单后切换项目应用和运行上下文，再返回工作区 | 菜单不残留、不重复；工作区、项目应用和运行上下文状态保持；无渲染异常 |
