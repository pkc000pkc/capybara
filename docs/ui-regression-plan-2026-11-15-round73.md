# UI 回归计划（Round73）

- 日期：2026-11-15
- 目标：验证顶栏浏览器/项目应用互斥切换入口和重复打开摘要去重。
- 约束：只通过 Electron 页面点击、输入和观察完成；本轮不修改代码。

## 用例

| ID | 场景 | 操作 | 预期 |
| --- | --- | --- | --- |
| R73-01 | 浏览器入口 | 点击浏览器网关 | 浏览器视图出现，顶栏显示“项目应用”切换按钮和浏览器关闭按钮。 |
| R73-02 | 重复打开 | 再次点击浏览器网关 | 浏览器视图不叠加，聊天区不新增第二条“已打开受控浏览器会话”摘要。 |
| R73-03 | 顶栏切换项目应用 | 点击浏览器工具条“项目应用” | 浏览器视图关闭，项目应用视图出现，顶栏不再显示浏览器工具条。 |
| R73-04 | 顶栏切换浏览器 | 点击应用视图状态下“打开浏览器” | 项目应用视图关闭，浏览器视图出现。 |
| R73-05 | 上下文一致性 | 打开执行过程 | Trace、browser_read 结果和项目应用状态保持可见。 |
