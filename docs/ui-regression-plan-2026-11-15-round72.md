# UI 回归计划（Round72）

- 日期：2026-11-15
- 目标：验证通用浏览器与项目应用视图互斥切换，并确认重复打开不再追加重复聊天摘要。
- 约束：只通过 Electron 页面点击、输入和观察完成；本轮不修改代码。

## 用例

| ID | 场景 | 操作 | 预期 |
| --- | --- | --- | --- |
| R72-01 | 浏览器打开 | 点击浏览器网关 | 浏览器视图出现，顶栏控件可见，新增一条浏览器摘要。 |
| R72-02 | 重复打开 | 再次点击浏览器网关 | 复用同一浏览器视图，不新增第二条相同摘要。 |
| R72-03 | 浏览器切到项目应用 | 点击打开 000682 行情看板窗口 | 通用浏览器视图先关闭，项目应用视图出现，顶栏切换为应用视图控制。 |
| R72-04 | 项目应用切回浏览器 | 点击浏览器网关 | 项目应用视图先关闭，浏览器视图重新出现，状态不叠加。 |
| R72-05 | 现有运行上下文 | 打开执行过程 | Runtime Trace、browser_read 结果和应用状态仍可见。 |
