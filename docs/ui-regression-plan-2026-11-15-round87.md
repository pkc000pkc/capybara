# Electron 页面回归计划（Round87）

日期：2026-11-15

本轮目标：覆盖 Round80–86 尚未形成稳定证据的项目应用控制面和运行上下文入口。

## 用例

| ID | 场景 | 操作 | 预期 |
|---|---|---|---|
| L01 | 项目应用页面切换 | 打开 qingjian-generated 项目应用，依次点击“总览”“内容与数据”“资料来源” | 三个页面内容分别对应摘要、研究步骤/结论、来源/产物，不出现跨页残留 |
| L02 | 应用打开入口 | 在总览页点击“打开应用”以及行情看板入口 | 应用状态、嵌入视图和窗口打开结果可见；失败显示可解释反馈 |
| L03 | 应用布局控制 | 点击“展开”和“收起” | 布局状态在工具栏更新，应用面板尺寸随操作变化，状态不丢失 |
| L04 | 运行上下文入口 | 点击“查看运行上下文”，依次查看时间线、进程、子智能体、证据治理 | 每个标签页内容与当前会话一致，空状态和非空状态均可见 |
| L05 | 全局设置入口 | 打开“工具/设置”或项目设置面板 | 全局模型状态、系统变量、工具/Skill 目录和资源修订可见；关闭后返回原页面 |

## 通过标准

- L01–L03 必须证明项目应用是可操作的控制面，不只是静态展示。
- L04 必须证明运行上下文的四个视图可切换且范围不跨项目。
- L05 必须证明设置面板可打开、读取和关闭，不泄漏 API Key。
- 页面操作期间不修改代码；完成后写入 `docs/ui-regression-report-2026-11-15-round87.md`。
