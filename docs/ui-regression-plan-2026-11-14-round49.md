# UI 黑盒回归计划（Round 49）

日期：2026-11-14  
范围：当前 Electron 构建的主工作区、菜单、项目会话、设置资源入口、运行上下文和项目应用入口

本轮只做页面点按和结果观察；不在执行中修改代码。每个用例先记录页面动作，再记录可见结果、状态变化和是否通过。

## 用例

| 编号 | 场景 | 操作 | 通过标准 |
| --- | --- | --- | --- |
| R49-01 | 顶部菜单入口 | 依次打开“文件、视图、工具、帮助”菜单，逐项点击可执行入口，关闭菜单后回到工作区 | 菜单不重复、不遮挡主区；可执行入口有页面结果或明确状态；无 IPC/渲染错误 |
| R49-02 | 项目侧栏与会话操作 | 使用搜索框过滤项目/会话，打开一个已有会话，新建会话，再切回原会话 | 当前项目和会话标题正确；会话内容不串项目；新会话只出现一次且消息区为空 |
| R49-03 | 设置与资源入口 | 从工具菜单打开项目设置与资源，查看模型、变量、工具、Skill、Harness 和 revision，关闭后重开 | 设置可达；资源来源和 revision 可见；关闭/重开不丢状态、不显示旧项目资源 |
| R49-04 | 运行上下文全页签 | 打开“执行过程”，依次查看时间线、进程、子智能体、证据治理，关闭并重新打开 | 各页签可切换；计数和内容属于当前会话；关闭/重开可恢复；无旧项目轨迹串入 |
| R49-05 | 项目应用入口 | 打开项目应用面板，查看总览、内容与数据、资料来源，关闭面板后重新打开 | 面板可打开/关闭；页签内容稳定；应用状态、地址和版本表达一致；关闭面板不改变会话 |
