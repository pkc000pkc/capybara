# UI 回归计划（Round71）

- 日期：2026-11-15
- 目标：验证 Round70 发现的浏览器未授权地址复用缺陷已经修复，并复测通用浏览器与项目应用隔离。
- 约束：只通过 Electron 页面点击、输入和观察完成；本轮不修改代码。

## 用例

| ID | 场景 | 操作 | 预期 |
| --- | --- | --- | --- |
| R71-01 | 正常打开 | 点击“浏览器网关” | Example Domain 出现，浏览器顶栏控件和 URL 正常。 |
| R71-02 | 拒绝地址 | 输入 `https://evil.example/` 并提交 | 显示策略错误，页面仍保持最后确认的 Example Domain。 |
| R71-03 | 拒绝后关闭 | 点击“关闭浏览器” | 浏览器视图消失且地址状态不会继续使用未授权 URL。 |
| R71-04 | 拒绝后重新打开 | 再次点击“浏览器网关” | 能重新打开最后确认页面，不重复触发未授权 URL 错误。 |
| R71-05 | 重复打开 | 再次点击“浏览器网关” | 同一浏览器实例复用，不叠加视图、不报重复打开错误。 |
| R71-06 | 项目应用隔离 | 打开 000682 行情看板 | 项目应用视图仍可打开，浏览器会话控件和应用视图状态分离。 |
