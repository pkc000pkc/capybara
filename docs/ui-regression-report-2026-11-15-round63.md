# Capybara V2 页面回归报告（Round63）

## 结论

本轮使用最新 Workbench 构建并通过标准 `npm run desktop:start` 启动 Electron，专门复测项目应用恢复时序。所有 6 个用例通过：启动恢复、跨项目回切、当前项目重复点击、历史会话切换、基础发送和空输入门禁均有页面证据。

项目应用恢复期间，右侧面板会显示“正在恢复项目应用”“恢复中”“正在读取项目应用状态”，能力入口和应用操作按钮处于禁用状态；恢复完成后恢复 `000682 行情看板`、`v1 · 已发布`、发布地址、研究结果和能力连接状态。

## 修复验证

- 应用恢复增加独立状态，不再把 `applicationRuntime=null`、`marketResearch=null` 的异步窗口直接表现为真实空白应用。
- 恢复期间禁用启动、打开、停止、重启、更新、回滚、布局和能力入口，避免在快照未完成时触发错误动作。
- 以恢复代数丢弃旧项目请求，避免跨项目异步返回覆盖当前项目。
- 启动、项目切换、会话切换和打开本地项目均走统一的项目应用恢复路径。

## 阶段判断

Round63 关闭了 Round62 的项目应用恢复时序缺口。当前页面已能区分真实空白应用与异步恢复状态，基础项目/会话/应用闭环继续可用。仍需继续关注的产品缺口包括交互式浏览器能力、研究动作 Trace 的统一回放、应用异常生命周期和菜单入口的完整动作语义。
