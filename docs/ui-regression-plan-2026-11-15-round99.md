# UI 回归测试计划（Round 99）

## 目标

验证 Round 98 修复后的“打开本地项目并取消”行为，不改变当前项目选择、会话轨迹、运行状态和页面入口。

## 页面用例

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| R99-1 | 启动最新构建并打开已有项目 | 项目、会话和工作区正常恢复 |
| R99-2 | 点击“打开本地项目” | 显示系统目录选择器，原工作区保持可恢复 |
| R99-3 | 在目录选择器中点击取消/Esc | 当前项目名称、项目目录状态、当前会话和消息轨迹保持不变；只显示取消提示 |
| R99-4 | 取消后打开运行上下文 | 时间线、进程、子智能体和证据治理入口仍可用 |
| R99-5 | 取消后打开项目应用 | 项目应用入口仍可达，不出现空白未打开项目页 |
| R99-6 | 取消后发送空指令 | 输入区和发送按钮仍保持空闲状态，不出现运行时断开 |

## 通过标准

取消目录选择只产生提示，不改变 activeProjectId、activeSessionId、localProject 或 opaqueDirectoryRef；页面能继续回到原工作区。
