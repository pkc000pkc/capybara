# UI 黑盒回归计划（Round 52）

日期：2026-11-15  
范围：当前 Electron Workbench 构建  
规则：本轮只通过页面、菜单、原生选择器和按钮操作验证，不修改实现。

## 用例

| 编号 | 用例 | 通过标准 |
|---|---|---|
| R52-01 | 文件菜单完整入口 | 新会话、打开项目、项目文件、导出快照均可被命中；每个入口有明确页面结果，且菜单操作不会误触发新会话 |
| R52-02 | 视图、工具、帮助菜单 | 侧栏切换、深色模式、项目资源、运行上下文、设置、关于弹窗均能打开或产生明确结果 |
| R52-03 | 项目与会话切换 | 项目列表只显示存在项目；切换会话后消息和标题对应当前会话，无重复显示 |
| R52-04 | 输入与单次发送 | 输入一条消息后只产生一条用户消息，发送后能看到运行状态、回复或明确错误 |
| R52-05 | 运行上下文 | 打开后能看到阶段摘要、工具/进程/子智能体/时间线和证据治理；关闭后可重新打开 |
| R52-06 | 项目应用 | 项目应用面板可打开；能看到版本、运行状态、能力、来源和产物；打开/关闭应用视图不遮住主菜单 |
| R52-07 | 设置与资源 | 能打开项目设置、读取模型配置状态、看到变量与资源来源；关闭后回到当前项目 |
| R52-08 | 项目关闭与重开 | 关闭项目后当前内容清空或进入空状态；重新打开同一目录后项目和会话恢复 |

## 记录方式

每个用例记录“通过、部分通过、失败或未完成”，并保留页面文字、辅助功能树或截图证据。若按钮只是显示“入口已保留”，标记为入口反馈，不视为完整功能通过。
