# UI 黑盒回归计划（Round 25）

日期：2026-11-14  
范围：运行上下文证据治理详情视图

## 目标

验证运行上下文不再只显示候选、证据和收据计数，而是能够独立展开、检索和复制治理记录，并保持与现有时间线一致。

## 用例

| 编号 | 页面操作 | 预期 |
| --- | --- | --- |
| R25-01 | 打开已有运行上下文，切换到“证据治理”页签 | 页签可见，显示候选、证据、应用收据及审核记录的数量和详情入口 |
| R25-02 | 在治理筛选框输入一个已知 `callId` 或 `candidateId` | 只保留匹配记录，其他记录隐藏；清空筛选后恢复完整列表 |
| R25-03 | 展开一条候选/收据记录并点击“复制 JSON” | 能看到结构化字段；复制按钮反馈“已复制”，记录内容与运行时快照一致 |

## 记录方式

记录页签、筛选结果、展开内容和复制反馈的页面文本/截图。若当前运行没有治理记录，至少验证空状态、筛选控件和页签可达性，并把数据缺失与视图缺失分开记录。
