# Electron 页面回归计划（Round83）

日期：2026-11-15

本轮目标：验证 R82-ART-001 修复，不扩大测试范围；先启动包含修复的最新 Workbench 构建，再通过页面操作检查产物治理反馈和状态更新。

## 用例

| ID | 场景 | 操作 | 预期 |
|---|---|---|---|
| G01 | 复核反馈可见 | 打开 qingjian-generated 项目应用，进入“资料来源”，滚动到产物列表，点击第一个研报的“复核” | 当前项目应用滚动区显示 `role=status` 的复核结果或明确失败原因；不能只在设置弹窗出现 |
| G02 | 治理结果即时更新 | 在 G01 后观察产物卡片和按钮状态 | 产物状态、按钮可用性和状态提示与后端返回一致；请求进行中按钮短暂禁用，完成后恢复或消失 |
| G03 | 治理反馈持久化 | 切换到另一个项目，再切回 qingjian-generated，重新打开资料来源并滚动到产物区 | 产物状态和复核反馈对应当前项目，不被旧项目覆盖；页面可以重新读取治理后的状态 |

## 通过标准

- G01 必须在项目应用页面直接看到结果或失败原因。
- G02 不允许出现无反馈的静默操作。
- G03 切换项目后不能显示其他项目的治理状态。
- 页面操作期间不修改代码；完成后写入 `docs/ui-regression-report-2026-11-15-round83.md`。
