## 本轮确认的缺口

1. **项目应用选择没有随项目重开恢复。** 关闭并重新打开同一目录后，历史会话恢复，但右侧项目应用回到空白 v1；此前已完成的市场研究应用仍存在于项目数据中，却没有被选中或恢复展示。
2. **项目级设置/资源读取失败。** 设置页在全局模型配置正常、聊天可用的情况下，仍报告项目提示词变量和项目资源目录读取失败。这会直接影响项目提示词、资源、工具和 Skill 的产品化闭环。
3. **项目侧栏切换的视觉语义不完整。** 菜单动作有可见反馈，但左侧会话列表仍留在页面上；“收起项目侧栏”与“项目/会话列表全部隐藏并可恢复”的验收语义尚未闭合。
4. **搜索结果的层级语义不够明确。** 搜索词命中项目级信息时保留该项目的全部会话；需要明确这是预期的项目聚合搜索，还是应只保留命中的会话。

## 当前结论

Round 13 的基础导航、项目关闭/重开、会话切换、运行上下文、设置入口和实际发送链路可用。项目应用持久化选择、项目资源读取以及侧栏交互仍未达到可验收的闭环标准；本轮尚未修改代码，下一步只针对这些本地前端/状态恢复缺口进行修复并重跑相关用例。
