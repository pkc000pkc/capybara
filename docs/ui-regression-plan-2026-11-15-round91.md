# Electron 页面回归计划（Round91）

日期：2026-11-15

本轮目标：实际触发无效文件参数，验证失败终态与重试上限。

## 用例

| ID | 场景 | 操作 | 预期 |
|---|---|---|---|
| P01 | 不存在文件 | 发送“只调用一次 read_file 读取项目根目录下不存在的 `__capybara_missing__.txt`，失败后立即停止，不要重试、不要修改文件” | 产生一次 `read_file` 失败，页面显示工具名、错误原因、耗时和最终状态。 |
| P02 | 失败轨迹 | 任务执行中或结束后打开执行过程与运行上下文 | 能看到失败调用、结果回传、重试次数（若存在）和当前任务关联信息。 |
| P03 | 失败后恢复 | 任务结束后发送“只回复 OK，不调用工具” | 后续请求正常完成，失败轨迹仍保留。 |

## 通过标准

- P01 必须以实际页面行为为准，不采信模型口头声称。
- P02 记录是否发生额外工具调用以及每次错误。
- P03 验证失败不会阻塞 Runtime。
- 本轮不修改代码，先写报告再决定是否修复。
