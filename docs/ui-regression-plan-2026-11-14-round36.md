# UI 黑盒回归计划（Round 36）

日期：2026-11-14  
范围：设置入口局部修复后的页面回归

## 目标

验证设置快捷键修复没有破坏设置内容、扩展资源空输入校验、设置关闭/重开以及当前项目的应用和运行状态。

## 用例

| 编号 | 页面操作 | 预期 |
| --- | --- | --- |
| R36-01 | 使用 `Ctrl+Comma` 打开设置 | 稳定出现“项目设置与资源”对话框 |
| R36-02 | 保持 GitHub 仓库和 Skill 路径为空，触发“预览 Skill” | 显示明确的仓库和路径校验，不发起安装 |
| R36-03 | 保持插件目录为空，触发“预览并安装插件” | 显示明确的项目内插件目录校验，不生成资源 |
| R36-04 | 关闭设置，再使用快捷键重开 | 全局模型配置、密钥配置状态和资源目录仍可见 |
| R36-05 | 返回工作区后打开运行上下文 | 应用、会话和证据状态保持不变，运行上下文可重新进入 |

## 判定规则

- 只用 Electron 页面和可见状态判定。
- R36-01 至 R36-04 必须有页面文字或控件状态证据。
- R36-05 分开记录“状态保持”和“运行上下文入口”两个结果，不能用上一轮证据替代本轮入口验证。
- 本轮不修改代码；若发现缺陷，下一轮单独处理。
