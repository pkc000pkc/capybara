# Electron 页面回归计划（Round88）

日期：2026-11-15

本轮目标：验证“当前会话内的非空运行轨迹”是否能从用户指令实时进入页面，并可在任务结束后回放。

## 用例

| ID | 场景 | 操作 | 预期 |
|---|---|---|---|
| M01 | 最小只读工具任务 | 在当前 qingjian-generated 会话发送“读取项目根目录并读取一个小文件前 3 行，不要修改文件” | 页面出现模型阶段摘要、工具调用、工具结果和最终回复；工具参数不泄漏密钥。 |
| M02 | 运行中上下文 | 任务执行期间打开“查看运行上下文” | 时间线从 0 增长；进程显示工具/脚本运行状态；阶段和状态与聊天区一致。 |
| M03 | 完成后关联 | 任务完成后查看时间线、证据治理和聊天区 | 能看到工具结果、证据/收据、最终回复，并能关联同一轮运行。 |
| M04 | 会话回放 | 关闭并重新打开当前项目或重新选择该会话 | 已完成任务的消息和运行轨迹仍可见；关键关联 ID 和完成状态不丢失。 |

## 通过标准

- M01 必须至少产生两个只读工具调用，并且最终回复明确基于工具结果。
- M02 必须证明当前会话的非空时间线和进程状态可以实时观察。
- M03 必须证明聊天内容与运行上下文不是两套互不关联的展示。
- M04 必须证明历史会话回放包含运行轨迹，而不是只有聊天消息。
- 本轮只做页面操作，不修改代码。
