## 修复确认

- Fastify artifact 路由已支持长结构化 ID，页面审核不再触发默认参数长度限制。
- 前端以项目 Artifact Index 的状态覆盖同 ID 的研究结果状态，消除了升级后旧卡片与索引卡片重复呈现。
- 项目切换仍保持资源状态隔离，审核结果写入项目目录并可恢复。

## 后续缺口

1. “复核”按钮缺少唯一的可访问名称，且窄侧栏下坐标命中困难；建议为复核/接受/拒绝补充带 artifactId 的 `aria-label`，并为产物卡片提供稳定的测试定位。
2. 不同历史 run 的同类产物仍会逐条展示；若产品希望按当前版本聚合，需要增加按 run/version 的折叠或筛选，而不是继续依赖列表去重。
