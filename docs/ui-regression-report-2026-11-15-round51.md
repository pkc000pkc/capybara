## 新发现

1. 文件菜单打开后，使用键盘 Down/Return 没有稳定地作用于菜单项，而是触发了新会话快捷键。页面结果是创建了一个新的空会话；未发现重复创建，但菜单焦点管理需要复核。
2. 原生目录选择器可以打开并通过 Escape 取消，页面给出明确取消反馈；本轮没有选择目录，因此没有改变登记项目。
3. 项目应用当前页面状态可见：`运行实例：已停止`、`发布内容：已发布`、`嵌入视图：未打开`、`布局：侧栏`，研究闭环、来源证据和产物版本仍保持。

## 本轮结论

Round51 没有发现项目应用和运行上下文的新渲染阻塞，但没有完成全部按钮矩阵；菜单焦点和项目文件入口需要在修复轮后重新点按。下一轮修复前，先处理已确认的训练状态机问题，再重新构建并执行完整页面回归。
