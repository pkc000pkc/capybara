# UI 黑盒回归计划（Round 26）

日期：2026-11-14  
范围：工具进程的执行目录边界表达

## 目标

验证运行上下文的进程页能把工具进程与项目目录边界关联起来，至少显示执行范围和相对 cwd，避免用户只能看到 PID 而无法判断结果归属。

## 用例

| 编号 | 页面操作 | 预期 |
| --- | --- | --- |
| R26-01 | 新会话发送只读 `run_command` 指令，要求在项目目录执行 `pwd`/`cd` 等价命令 | 工具完成；时间线和进程状态可见；运行进程显示“执行边界：project · cwd .”或用户指定的项目相对目录 |
| R26-02 | 打开运行上下文并切换“进程”页签 | 进程条目显示工具名、状态、PID（如有）、时间和执行边界；不会暴露绝对路径或系统目录 |
| R26-03 | 重新打开运行上下文 | 执行边界字段仍从可回放快照恢复，和工具结果中的 cwd 一致 |
