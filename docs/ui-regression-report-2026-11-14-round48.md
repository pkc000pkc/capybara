## 修复验证

- 新项目初始化不再把系统文件工具复制进项目，配置记录项目资源为空列表。
- Backend `ProjectResources` 对显式空列表仍合并系统默认工具和 Skill。
- 工具注册器和 Electron 运行时会把与系统文件完全相同的历史项目副本视为系统回退；有实际改动的项目副本仍保持项目优先。
- 前端资源加载使用请求代际保护，旧项目异步响应不会覆盖当前项目。

## 结论

资源来源、项目隔离、聊天发送和运行上下文基础闭环通过。本轮没有验证同名但内容不同的项目资源覆盖、有效插件安装依赖冲突、超时/断线/应用回滚等既有 P1 失败路径；产品化验收仍需继续施工。
