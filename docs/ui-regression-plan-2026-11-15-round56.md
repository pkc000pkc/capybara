# Capybara V2 页面回归计划（Round56）

## 目的

验证 renderer 移除市场研究 `localStorage` 独立状态源后，研究结果只按当前项目 Runtime Trace 恢复，项目切换时不会串用上一个项目的研究结果。

## 用例

| 编号 | 页面动作 | 通过标准 |
|---|---|---|
| R56-01 | 启动最新构建并打开已有研究项目 | 研究结果来自当前项目会话/Trace；页面可显示研究步骤、证据或产物，且不依赖旧 renderer 缓存 |
| R56-02 | 从研究项目切换到空项目，再切回研究项目 | 空项目不显示研究项目的行情结果；切回后能从当前项目 Trace 恢复对应结果 |
| R56-03 | 关闭并重新打开研究项目 | 研究结果、项目应用状态和会话仍来自项目持久化数据；页面不依赖浏览器 localStorage 才能恢复 |

## 记录要求

- 只通过 Electron 页面和原生项目选择器操作。
- 记录切换前后的项目名称、应用页签内容和研究结果状态。
- 本轮不修改实现；发现问题后结束本轮再单独修复。
