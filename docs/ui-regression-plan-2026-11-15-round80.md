# Electron 页面回归计划（Round80）

日期：2026-11-15

本轮目标：依据当前 Workbench 页面实际可见控件，逐项验证项目/会话、运行上下文、项目应用、资源管理、浏览器入口、应用运行和帮助菜单；每个用例只记录页面可观察结果，不在操作过程中修改代码。

## 执行规则

- 先确认当前窗口、项目和会话，再执行按钮操作。
- 每个按钮记录：点击前状态、点击动作、页面反馈、是否可回退、是否产生重复请求或重复内容。
- 对会触发外部副作用的按钮只验证入口和门禁提示，不提交未经授权的外部动作。
- 运行上下文中的“思考”只验收结构化阶段摘要、工具状态和证据，不验收隐藏的原始链式思考。
- 本轮结束后先写回归报告，再决定是否进入修复轮。

## 页面和按钮用例

| ID | 页面/区域 | 操作 | 预期 |
|---|---|---|---|
| P01 | 顶部菜单 | 文件、视图、工具、帮助依次打开 | 菜单不重复、不遮挡主工作区；关闭后恢复原布局 |
| P02 | 项目栏 | 打开本地项目 | 目录选择后只显示存在项目；项目级 `.capybara` 自动可用 |
| P03 | 项目栏 | 新会话 | 只创建一个会话；旧会话不被复制；新会话进入当前项目 |
| P04 | 项目栏 | 点击已有会话 | 加载该会话消息、Trace 和运行状态；不显示其他会话内容 |
| P05 | 项目栏 | 搜索项目或会话 | 结果与输入匹配；清空后恢复；无结果有明确空态 |
| P06 | 项目栏 | 项目折叠/展开 | 只影响当前项目树；会话层级和项目数不重复 |
| P07 | 项目栏 | 关闭项目 | Runtime、应用、浏览器和项目会话停止；项目从当前工作区消失但历史注册可按产品规则保留 |
| P08 | 聊天输入 | 输入一次并发送 | 用户消息只出现一次；按钮禁用/恢复正确；Agent 回复与请求关联 |
| P09 | 聊天输入 | Ctrl+Enter 发送、空输入发送 | Ctrl+Enter 只发送一次；空输入不创建消息 |
| P10 | 聊天输入 | 发送期间切换会话/项目 | 原请求继续或安全停止；结果不串到新会话/项目 |
| P11 | 运行栏 | 立即运行、暂停任务、停止本轮 | 状态按 running/waiting/stopped 更新；按钮只在允许状态出现 |
| P12 | 运行上下文 | 打开/关闭运行上下文 | 主聊天与运行上下文一致；关闭不丢状态 |
| P13 | 运行上下文 | 查看执行时间线 | 模型阶段摘要、工具名、参数摘要、开始/结束时间、耗时和结果可见 |
| P14 | 运行上下文 | 查看进程/子智能体 | 工具、脚本、父子任务状态可见；失败原因可展开 |
| P15 | 运行上下文 | 查看治理记录并筛选/复制 JSON | 候选、证据、收据可筛选；复制反馈明确 |
| P16 | 项目应用 | 打开项目应用、切换总览/内容与数据/资料来源 | 面板内容随 Tab 切换；当前项目内容不串项目 |
| P17 | 资料来源 | 复核产物 | 文件存在且哈希一致时显示通过；文件缺失/变化时显示对应状态 |
| P18 | 资料来源 | 接受、拒绝产物 | 状态更新一次；刷新后保持；产生治理记录 |
| P19 | 应用运行 | 启动、打开、停止、重启应用 | 应用进程状态可见；地址打开正确；失败时有具体原因 |
| P20 | 应用运行 | 切换侧栏/展开布局 | 只改变布局，不重置应用状态或会话 |
| P21 | 浏览器入口 | 打开浏览器、导航、后退/前进/刷新、关闭 | 受控页面可见；Origin Policy 拒绝时有明确提示；关闭后状态清理 |
| P22 | 浏览器动作 | 页面读取、截图、等待、断言、下载入口 | 结果进入运行上下文、证据和产物；失败可定位 |
| P23 | 系统资源 | 查看/编辑模型设置和变量 | 密钥不回显；保存后状态可见；只读变量不能被修改 |
| P24 | 系统资源 | 查看工具、Skill、Hook、Plugin 目录 | 项目资源优先，系统资源兜底；重复名称和缺失资源有提示 |
| P25 | 帮助 | 打开帮助/关于 | 弹层可关闭；版本和运行状态显示准确 |
| P26 | 重开 | 关闭并重新打开项目/会话 | 消息、Trace、工具调用、产物、应用和浏览器恢复状态可回放 |

## 通过标准

1. 每个按钮最多产生一次对应动作，不出现重复消息、重复会话或重复运行。
2. 页面显示的状态、运行上下文和项目应用内容来自同一个项目/会话。
3. 所有失败都显示阶段、原因和可恢复动作；未知状态不得显示为成功。
4. 运行完成后能回到会话历史，且 `turnId / stepId / callId`、工具结果、证据和产物可关联。
5. 本轮所有实际观察写入 `docs/ui-regression-report-2026-11-15-round80.md`。
