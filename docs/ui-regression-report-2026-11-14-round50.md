# UI 黑盒回归报告（Round 50）

日期：2026-11-14  
构建：当前标准 Electron 构建  
范围：帮助菜单、文件菜单剩余入口、工具菜单剩余入口、运行上下文和项目应用切换

## 结果

本轮 4 个用例 **4 个通过**。测试过程中没有修改实现。

| 编号 | 结果 | 页面证据 |
| --- | --- | --- |
| R50-01 关于概念稿 | 通过 | 使用“帮助 → 关于概念稿”菜单节点打开模态框；页面显示 `CAPYBARA WORKBENCH`、产品说明和“关闭关于窗口”；点击关闭后回到工作区 |
| R50-02 文件菜单剩余入口 | 通过 | “项目文件”显示“项目文件入口已保留，当前项目暂无可执行内容”；“导出项目快照”显示“导出项目快照入口已保留，当前项目暂无可执行内容” |
| R50-03 工具菜单剩余入口 | 通过 | “定时与触发”“能力演化”“Token 用量”分别显示对应的保留入口状态；菜单关闭后工作区仍可用 |
| R50-04 菜单交互稳定性 | 通过 | 关闭菜单后可打开运行上下文，看到时间线/进程/子智能体/证据治理页签；关闭后可打开项目应用，显示 `000682 行情看板`、运行实例、发布内容、嵌入视图、来源与产物状态 |

## 结论

Round49 的“帮助 → 关于概念稿无可见结果”已被复测修正为点击命中问题，当前实现可以正常显示和关闭模态框。文件和工具菜单的保留入口均能给出明确的状态反馈，因此本轮不再把它们判定为无响应按钮。

这些入口仍属于“状态反馈/保留入口”，尚未形成完整的文件浏览、快照导出、定时配置、能力演化和用量统计页面；它们仍是产品化后续缺口，但不属于本轮发现的渲染或点击故障。

本轮点按过程中产生了一个新的空会话，用于验证菜单与工作区切换后的稳定性；没有修改项目文件、安装资源或启动外部应用。
