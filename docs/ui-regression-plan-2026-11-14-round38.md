# UI 黑盒回归计划（Round 38）

日期：2026-11-14  
范围：应用状态三分轴和布局控制修复后的页面回归

## 目标

验证项目应用页面能独立表达托管实例、发布内容和嵌入视图三类状态，并且展开/收起控制在实例停止但已存在发布内容时仍可见、可操作、可回放。

## 用例

| 编号 | 页面操作 | 预期 |
| --- | --- | --- |
| R38-01 | 打开已有研究项目的项目应用面板，应用实例处于停止态 | 同时显示运行实例状态、发布内容状态、嵌入视图状态；不再把已发布内容显示成运行中 |
| R38-02 | 在停止态点击“展开”，再点击“收起” | 两次操作均可见；布局文案分别变为“展开”和“侧栏”，并显示对应反馈 |
| R38-03 | 点击“打开应用” | 内嵌看板打开，显示 `嵌入视图：侧栏`；关闭后恢复 `嵌入视图：未打开`，发布内容状态不丢失 |
| R38-04 | 在运行实例启动后打开面板 | 运行实例显示运行中并出现 PID/端口/健康状态；发布内容和嵌入视图状态仍独立显示 |
| R38-05 | 关闭并重新打开项目应用、运行上下文和当前会话 | 三类状态、布局状态、研究证据和会话轨迹不串线 |

## 判定规则

- 只用 Electron 页面实际可见文字、按钮状态和视图变化判定。
- 状态标签必须能明确区分“运行实例”“发布内容”“嵌入视图”。
- “调用成功”但页面无可见变化不算通过。
- 本轮不修改代码；发现问题时先完成整轮并记录，再进入下一轮修复。
