# Electron 页面回归计划（Round93）

日期：2026-11-15

本轮目标：验证默认 timeout 语义和工作区路径边界，并检查失败后的会话恢复。

## 用例

| ID | 场景 | 操作 | 预期 |
|---|---|---|---|
| T01 | 默认 timeout | 发送最小只读 `node -e` 命令，不显式传 `timeout_ms` | 页面显示正常工具调用、完成状态和收据；能判断是否保留默认超时信息。 |
| T02 | 工作区边界 | 读取项目外的确定不存在路径 `..\\..\\__capybara_outside__.txt` | 工具被拒绝或以明确路径错误失败，不泄露工作区外内容，不修改文件。 |
| T03 | 失败后恢复 | 失败结束后发送“只回复 OK，不调用工具” | 后续请求正常完成，前一轮错误仍可回放。 |

## 通过标准

- 只按页面实际事件、工具收据和最终状态判断，不采信模型没有证据的陈述。
- 记录是否出现显式 `timeout_ms`、错误码、路径边界信息、工具调用次数和恢复状态。
- 本轮不修改代码；整轮结束后再写报告和阶段审查。
