# UI 黑盒回归计划（Round 24）

日期：2026-11-14  
范围：父任务委派子智能体后的证据可见性与可回放性

## 目标

验证父任务收到子智能体结果时，页面和运行时上下文能同时保留：

- 父子任务关联（childId、父运行关联）；
- 子智能体的工具调用、观察状态和结果产物；
- 产物 hash / artifactId 等可独立核验字段；
- 子任务结束状态与父任务最终回复一致；
- 重新打开运行上下文后仍能看到子智能体轨迹。

## 用例

| 编号 | 页面操作 | 预期 |
| --- | --- | --- |
| R24-01 | 新会话发送“委派子智能体读取项目根目录并返回文件名，不修改文件” | 父消息完成；运行上下文出现子智能体条目，子任务为 succeeded；父结果含 childId 和证据包摘要 |
| R24-02 | 打开“执行过程与依据”的子智能体页签 | 能看到子任务状态和时间；父时间线中有委派工具调用；不把子代理文本冒充为工具事实 |
| R24-03 | 展开委派工具详情并重新打开运行上下文 | 可看到 childId、工具步骤/观察/产物计数或证据引用；刷新/切换上下文后关联仍存在 |

## 记录方式

记录页面截图、可见文本、AX 树中的关键字段，以及最终运行状态。若模型未触发委派，记录为环境阻塞，不把“未触发委派”误判为实现通过。
