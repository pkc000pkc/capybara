# UI 回归计划（Round76）

日期：2026-11-15

本轮针对 Round75 的 Browser Gateway、浏览器下载和 Runtime 工具结果收据改动，使用最新 Electron 构建做页面黑盒复测。测试只通过页面和桌面窗口操作完成，不通过代码替代页面证据。

## 用例

| 编号 | 场景 | 操作 | 通过标准 |
|---|---|---|---|
| R76-01 | Electron 冷启动 | 启动最新 Workbench，确认工作区、项目列表、输入区、项目应用入口和运行上下文入口 | 页面无启动错误，主工作区可操作 |
| R76-02 | 项目应用入口 | 点击项目应用，检查总览、内容与数据、资料来源三个页签，再关闭 | 三个页签可切换，关闭后主工作区恢复 |
| R76-03 | 运行上下文入口 | 打开执行过程，检查时间线、进程、子智能体、证据治理四个视图 | 四个视图可切换，空状态或记录状态清晰 |
| R76-04 | 浏览器宿主 | 通过浏览器网关入口打开 Example Domain，检查地址、后退、前进、刷新、关闭 | 页面加载成功，控制栏可见，关闭后工作区恢复 |
| R76-05 | 浏览器/项目应用互切 | 在浏览器视图和项目应用视图之间分别点击顶栏切换 | 两个视图互斥，切换后不重叠、不重复创建 |
| R76-06 | 主导航与输入区冒烟 | 点击文件、视图、工具、帮助菜单，检查设置/关于/项目侧栏/深色外观/发送入口 | 每个入口有可见结果，输入区仍可发送或给出明确门禁 |
| R76-07 | 项目切换隔离 | 在已登记项目之间切换，观察会话、应用面板和浏览器视图 | 不把其他项目的会话、地址或视图带入当前项目 |

- 记录浏览器宿主失败、地址拒绝、应用恢复和项目切换的可见错误。
