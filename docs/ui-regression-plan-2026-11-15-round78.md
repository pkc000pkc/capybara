# Electron 页面回归计划（Round78）

日期：2026-11-15

## 目的

验证本轮项目 Artifact 索引和项目应用面板恢复后，用户能够看到应用内容、资料来源和产物状态，且不会破坏现有项目切换、运行上下文和内嵌应用入口。

## 页面用例

1. 启动最新 Workbench，打开已登记项目，确认项目应用面板存在总览、内容与数据、资料来源三个页签。
2. 切换到“资料来源”，确认面板至少显示来源/产物内容，而不是只有应用运行工具栏。
3. 切换项目并返回，确认应用面板、页签和项目级状态没有串项目或消失。
4. 打开运行上下文，确认时间线、进程、子智能体、证据治理仍能正常显示。
5. 打开帮助菜单和关于弹窗，再关闭，确认顶部菜单没有重复渲染或遮挡应用内容。

## 通过标准

- 应用内容区域可见，三个页签可切换。
- 资料来源页能显示已持久化的来源/产物记录；若有可审核产物，显示接受/拒绝入口。
- 项目切换后只显示当前项目的应用和资料来源。
- 运行上下文和菜单交互无回归。
- 失败、空项目和无产物项目保持清晰的空状态。

## 约束

- 本轮只进行页面观察和交互，不在 UI 操作期间修改代码。
- 发现问题先记录证据，退出页面回归后再修复。
