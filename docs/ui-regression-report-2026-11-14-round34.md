- 关闭内嵌应用视图后，应用面板仍保持停止态。

判定：通过。运行实例的停止/重启状态能收束并恢复；停止态打开已发布看板仍需要在产品上明确其“发布内容宿主”语义。

## 本轮新增缺口

1. **展开/收起按钮无可见效果**：运行中、停止态和内嵌视图边界均未形成稳定的布局或文案变化。
2. **应用停止态的地址语义仍需收敛**：运行实例已停止，但已发布看板仍可打开；页面没有区分运行实例地址和已发布内容地址。
3. **设置菜单项激活链路不稳定**：设置项可见，但当前点按/键盘激活没有打开设置页面，Skill/插件校验无法继续验收。

## 下一轮建议

- 先为“展开/收起”定义可观察状态转移，再做页面修复或验收。
- 将运行实例地址和已发布内容地址拆成两个明确字段，并分别定义停止、打开、重启按钮的预期。
- 优先修复或明确设置菜单的激活方式，再补齐空 Skill、空插件目录、非法路径和有效路径四组用例。
