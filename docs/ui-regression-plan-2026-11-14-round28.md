# UI 黑盒回归计划（Round 28）

日期：2026-11-14  
范围：健康应用重启、内嵌视图关闭和项目切换清理

## 目标

验证项目应用在健康版本下的停止、重启、打开/关闭内嵌浏览器视图，以及切换项目后的实例和视图状态是否一致。

## 用例

| 编号 | 页面操作 | 预期 |
| --- | --- | --- |
| R28-01 | 在健康应用上点击“停止” | 页面显示已停止、地址待分配，PID/端口/健康状态不再作为运行状态保留 |
| R28-02 | 点击“重启” | 页面恢复 running、healthy、新 PID/端口和有效本地地址 |
| R28-03 | 点击“打开应用” | Electron 内嵌浏览器视图打开，应用页面可见 |
| R28-04 | 点击“关闭应用视图” | 浏览器视图关闭，但应用进程仍保持 running/healthy |
| R28-05 | 切换到另一个已登记项目 | 旧项目应用视图关闭，旧实例不被错误带入，新项目状态独立显示 |

## 判定规则

- 停止、重启、视图关闭和项目切换必须分别表达实例状态与视图状态。
- 旧项目的地址、PID、端口和浏览器视图不能残留到新项目。
- 每个按钮操作后的页面状态必须与下一次页面读取到的应用状态一致。
