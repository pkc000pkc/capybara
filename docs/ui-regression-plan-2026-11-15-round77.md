# UI 回归计划（Round77）

日期：2026-11-15

本轮针对 Browser Gateway 状态进入 RuntimeLoopState/SQLite 快照的改动，重启最新 Electron 后做恢复和隔离回归。

| 编号 | 场景 | 操作 | 通过标准 |
|---|---|---|---|
| R77-01 | 桌面重启恢复 | 关闭旧 Electron，启动最新构建，观察默认项目和当前会话 | 项目、会话正文、项目应用和运行入口恢复，不出现空白或错误页 |
| R77-02 | 项目隔离恢复 | 切换到另一个已登记项目，再切回研究项目 | 会话、应用版本、研究结果和上下文不串项目 |
| R77-03 | 运行上下文恢复 | 打开执行过程，切换时间线/进程/子智能体/证据治理 | 四个视图可用，历史工具结果和治理记录仍可读 |
| R77-04 | 浏览器宿主恢复 | 打开 Example Domain，切到项目应用，再切回浏览器并关闭 | 浏览器地址和页面状态正常，互切不重叠 |
| R77-05 | 主界面冒烟 | 打开视图/帮助菜单，关闭弹窗，确认输入区和项目应用仍可操作 | 页面无运行时错误，主工作区保持可用 |
