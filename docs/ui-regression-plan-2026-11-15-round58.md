# Capybara V2 页面回归计划（Round58）

## 目的

在 Round57 的项目级研究恢复通过后，继续对当前产品化界面的可观察闭环做页面黑盒回归，覆盖运行上下文、项目应用、菜单入口、浏览器入口和应用生命周期按钮。

## 用例

| 编号 | 页面动作 | 通过标准 |
|---|---|---|
| R58-01 | 打开“查看运行上下文”，依次检查时间线、进程、子智能体、上下文、候选/证据和回放页签 | 每个页签有明确内容或明确空状态；关闭后回到工作区。 |
| R58-02 | 打开“项目应用”，依次检查总览、内容与数据、资料来源，并操作打开/关闭应用视图、展开/收起 | 每个页签可切换；按钮有状态变化；没有空白或跨项目数据。 |
| R58-03 | 打开文件、视图、工具、帮助菜单，逐项点击当前可用入口 | 菜单能够打开和关闭；每个已实现入口有页面反馈或明确状态。 |
| R58-04 | 点击浏览器网关入口，检查受限浏览器读取结果和失败状态表达 | 页面能显示读取结果或具体失败原因，不出现无响应。 |
| R58-05 | 在研究项目与空项目之间切换，检查项目应用、运行上下文和资源状态是否同步 | 所有主区域只显示当前项目内容，切换后没有残留。 |

## 记录要求

- 只通过最新 Electron 页面和原生项目选择器操作。
- 不在本轮操作中修改代码；发现问题后先完成整轮，再单独修复。
- 记录每个按钮的可见反馈、状态变化、错误信息和项目归属。
