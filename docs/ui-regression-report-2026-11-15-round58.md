## 观察到的产品缺口

1. 浏览器入口当前证明的是受限读取和研究编排，尚未覆盖公共网页的导航、点击、输入、下载、页面状态保存和回放。
2. 从项目应用面板直接触发市场研究时，结果卡片和聊天结果可见，但研究动作还没有完全并入统一的 Runtime Trace、工具收据和最终回复回放索引。
3. 菜单入口能够被发现，但本轮没有重新执行每个菜单命令；在完整产品验收前仍应维护菜单动作矩阵，避免“有入口、无可观察结果”的回归。
4. 应用实例的正常启停已经可见，更新失败回滚、后台实例策略、异常退出和项目快速切换期间的实例收束仍需要连续页面场景。
5. Backend 仍保留旧 WebSocket transport 和 Runner 接口；Electron 主链路使用 IPC，但协议边界和兼容层退出策略尚未收敛。

## 阶段判断

V2 Runtime 的最小可运行、可观测、可回放闭环继续成立。项目隔离、研究结果持久化、运行上下文和项目应用页面没有出现回归。产品化整体验收尚未完成，下一阶段应优先把交互式浏览器、研究动作 Trace 统一和应用异常生命周期纳入可重复的页面用例。
