# UI 黑盒回归计划（Round 42）

日期：2026-11-14  
范围：空项目自动初始化修复后的项目打开、资源设置、会话连接与项目隔离

## 目标

确认用户打开一个空目录后，系统会先完成项目级 `.capybara` 初始化，再进入正常的项目资源、会话和运行时路径；设置页不再把“目录未初始化”显示为资源读取失败。

## 用例

| 编号 | 页面操作 | 预期 |
| --- | --- | --- |
| R42-01 | 选择或切换 `ui-regression-clean-2026-11-14` 空项目 | 页面显示目录已登记；空项目初始化完成，不出现“项目提示词变量、项目资源目录读取失败” |
| R42-02 | 在初始化后的空项目打开设置 | 全局模型、变量和资源目录可读；项目资源为空时显示明确空状态或系统回退来源；不显示初始化错误 |
| R42-03 | 在空项目发送一条只读指令并查看运行上下文 | 会话可以连接，消息、模型阶段和运行上下文正常记录；项目目录不再被视为未初始化 |
| R42-04 | 关闭并重新打开空项目，再重开设置 | `.capybara` 初始化结果、会话记录和资源状态保持，不重复报初始化失败 |
| R42-05 | 切回 `qingjian-generated` | 000682 研究、项目资源和应用状态保持；空项目初始化内容不串入原项目 |

## 判定规则

- 先执行完整页面回归，再决定是否继续修复。
- 页面可见状态、资源列表和项目切换结果必须同时支持通过结论。
- 本轮不接受仅凭目录存在或代码调用成功作为初始化完成证据。
