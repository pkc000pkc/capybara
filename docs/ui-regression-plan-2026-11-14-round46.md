# UI 黑盒回归计划（Round 46）

日期：2026-11-14  
范围：系统工具/Skill 的项目优先与系统回退实际表现

## 目标

确认空项目和已有项目是否按照设计加载系统级文件工具与 Skill：项目存在同名资源时项目优先；项目没有时明确显示系统回退；资源来源与实际生效项一致。

## 用例

| 编号 | 页面操作 | 预期 |
| --- | --- | --- |
| R46-01 | 空项目打开设置并查看资源目录 | `project-files` 工具明确显示系统回退；没有复制成项目资源的假象 |
| R46-02 | 空项目查看默认 Skill | 系统级 `project-files` Skill 可见并标记系统回退，或页面明确说明当前项目没有该 Skill 的生效配置 |
| R46-03 | 切换到 `qingjian-generated` | 文件工具、Skill、harness 的来源标签与实际解析路径一致 |
| R46-04 | 关闭并重开设置、再切换项目 | 来源标签、revision 和生效资源不因重开或切换改变 |
| R46-05 | 切回空项目并打开运行上下文 | 资源来源变化不影响会话、时间线和证据治理状态 |

## 判定规则

- 页面显示的来源必须与实际生效路径一致。
- “项目资源”不能只是初始化复制的系统文件；若采用复制策略，页面必须明确说明其托管性质和覆盖规则。
- 先完成全轮页面验证，再决定是否调整初始化或默认资源配置。
