# Capybara Workbench 全页面黑盒回归用例（Round 14）

本轮先建立用例，再通过已启动的 Electron 页面逐项点击验证。禁止用代码级测试替代页面验收；代码和自动化测试只能作为辅助证据。

## 记录规则

- 每个用例记录：开始状态、点击/输入、页面可见反馈、结果、缺陷编号。
- `通过`：动作有可见反馈，且结果与预期一致。
- `部分通过`：主动作完成，但页面状态或后续闭环不完整。
- `失败`：动作无效、报错、状态错误或结果不可验证。
- 菜单中的未实现业务入口也必须点击，记录其反馈，不得只因为“能打开菜单”就判定通过。
- 测试顺序：先完成本轮全部点击和记录，再集中修复局部逻辑缺陷，最后执行第二轮复测。

## 本轮验收门槛

- A–I 所有页面入口和按钮均已点击并有记录。
- J 至少完成读取文件、执行代码、工具失败、应用启动四条链路；股票链路单独记录网络或模型阻塞。
- 第一轮完成后才能修改实现。
- 第二轮必须复测第一轮所有失败/部分通过用例，并重新检查主导航和高风险按钮。
