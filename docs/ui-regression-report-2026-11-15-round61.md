# Capybara V2 页面回归报告（Round61）

## 结论

本轮补测主导航、窗口恢复、搜索、项目与历史会话、运行上下文、项目应用页签、状态入口和基础发送。运行上下文四个页签、项目应用的内容/来源页、市场研究状态入口和基础聊天均有页面反馈；发现项目选择或历史会话切换后，已发布的 000682 看板状态会回落为“空白应用/未发布”，需要继续修复。没有出现新的发送阻塞。

## 新增缺口

1. **项目/会话切换后的应用状态回落（P1）**：同一项目在已有已发布研究看板时，点击项目行或切换历史会话会出现 `v1 · 空白应用`、`未发布` 和“本地地址待分配”；研究结果只有再次触发市场研究入口后才恢复。项目、会话、应用版本和研究持久化状态需要统一恢复。
2. **搜索无匹配缺少空状态（P2）**：过滤结果为空时没有明确提示，用户只能通过列表消失推断搜索结果为空。
3. **窗口最大化/还原缺少独立证据（P2）**：当前系统有多个 Electron/桌面窗口，页面回归无法稳定确认最大化后的布局是否保持一致。

## 阶段判断

Round61 证明聊天发送、研究入口、运行上下文治理和项目应用页签可继续使用；项目应用的持久化状态在项目/会话切换边界仍未闭环。下一轮应先修复应用状态恢复，再复测项目行、历史会话、项目关闭/重开和桌面重启组合路径。
