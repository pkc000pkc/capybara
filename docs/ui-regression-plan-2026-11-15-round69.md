# UI 回归计划（Round69）

- 日期：2026-11-15
- 目标：验证通用浏览器宿主接入 Electron IPC、Preload、Workbench 顶栏后的真实桌面链路，并确认项目应用视图仍可独立工作。
- 约束：只通过 Electron 页面点击、输入和观察完成；不在本轮 UI 操作中修改代码。

## 用例

| ID | 场景 | 操作 | 预期 |
| --- | --- | --- | --- |
| R69-01 | 启动和项目恢复 | 启动标准 Electron，观察已登记项目和会话 | 页面正常加载，项目应用恢复状态明确，不出现 IPC 初始化错误 |
| R69-02 | 打开通用浏览器 | 在项目应用面板点击“浏览器网关” | 顶栏出现浏览器地址、导航、刷新、关闭控件；右侧出现受控公共网页 |
| R69-03 | 浏览器导航 | 修改地址为允许的 Investor.gov 路径并提交 | 页面发生导航，顶栏 URL/标题状态同步；未创建第二个浏览器实例 |
| R69-04 | 浏览器控制 | 点击后退、前进、刷新 | 控件可用，页面状态保持在当前浏览器会话内，没有影响项目应用进程 |
| R69-05 | 浏览器关闭 | 点击“关闭浏览器” | 浏览器视图和顶栏控件消失，项目应用面板仍可打开 |
| R69-06 | 项目应用隔离 | 打开 000682 行情看板或项目应用 | 仍使用项目应用视图和本地地址，不被通用浏览器会话复用或覆盖 |
| R69-07 | 页面错误表达 | 输入不允许的外部地址并提交 | 页面显示受控策略错误，浏览器视图不跳转到未授权来源 |
| R69-08 | 现有聊天链路 | 发送一条短指令并打开执行过程 | 发送只产生一条用户消息，原有思考摘要、工具轨迹和运行上下文仍可见 |
