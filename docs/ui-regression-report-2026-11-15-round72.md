# UI 回归报告（Round72）

- 日期：2026-11-15
- 构建：`npm run desktop:start --workspace=apps/workbench`
- 关联计划：[Round72 计划](ui-regression-plan-2026-11-15-round72.md)

## 结果

| 用例 | 结果 | 观察 |
| --- | --- | --- |
| R72-01 | 通过 | 浏览器视图打开，地址、页面和顶栏控件正常。 |
| R72-02 | 通过 | 同一浏览器会话复用；重复打开不新增 WebContentsView，但修复前构建仍会追加重复摘要。 |
| R72-03 | 未通过 | 浏览器视图覆盖了右侧项目应用面板，面板按钮无法可靠触发项目应用切换。 |
| R72-04 | 未通过 | 同样的覆盖关系使浏览器/项目应用之间缺少稳定的顶层切换入口。 |
| R72-05 | 通过 | 现有 Trace、browser_read 结果和项目研究状态仍然可见。 |

## 结论

互斥关闭逻辑已经写入函数，但仅依靠右侧面板按钮不足以触发；通用浏览器视图覆盖了面板后，用户无法稳定点击面板中的项目应用按钮。需要在始终可见的顶栏浏览器工具条中增加“项目应用”切换按钮，并在项目应用视图状态下增加“打开浏览器”按钮。
