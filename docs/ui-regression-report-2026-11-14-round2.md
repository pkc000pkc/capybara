## 第二轮新增缺陷

### R2-01 关闭项目的 Electron 边界调用错误

- 重现：点击项目行右侧管理箭头，再点击“关闭项目”。
- 页面结果：出现 `Error invoking remote method 'capybara:close-project': TypeError: runtimeManager?.closeWorkspace is not a function`。
- 影响：项目关闭动作没有完成，列表和当前项目保持不变。
- 修复范围：Electron `close-project` IPC 处理器应调用当前 Runtime Manager 实际提供的关闭接口，或安全地跳过不存在的 workspace 方法后继续清理项目登记；不改变 RuntimeLoop 协议。
