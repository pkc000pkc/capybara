# UI 页面全量回归测试计划（Round 98）

## 目标

按页面控件逐项检查当前 Electron 工作台的主要页面、菜单、项目管理、会话、运行上下文、项目应用和工具/技能管理入口。每个控件都必须通过页面操作验证可用性、状态反馈和返回路径；本轮完成后再统一沉淀报告，不在测试中途修改代码。

## 测试方式

- 只使用 Electron 页面可见控件、页面输入和页面显示结果。
- 不以代码级单元测试作为本轮验收证据。
- 每个测试动作记录页面结果、是否可回退、是否产生持久化副作用。
- 只读优先；涉及新会话、项目关闭、菜单打开等可逆动作时完成后恢复原页面。

## 控件覆盖矩阵

### A. 顶部应用菜单

1. 文件菜单：打开项目、关闭项目、退出/相关入口。
2. 视图菜单：侧栏、运行上下文、项目应用等入口。
3. 工具菜单：系统配置、工具/技能管理或相关入口。
4. 帮助菜单：帮助/关于入口和返回路径。
5. 顶部后退、前进、最小化、最大化、关闭窗口的可见状态。

### B. 项目与会话侧栏

1. 收起/展开项目侧栏。
2. 新会话。
3. 打开本地项目入口（取消路径也要可回退）。
4. 搜索项目或会话。
5. 项目选择、展开/收起项目会话列表。
6. 项目管理入口：关闭项目、项目设置或相关管理页面。
7. 会话条目切换与会话轨迹恢复。

### C. 工作区与运行上下文

1. 查看运行上下文。
2. 项目应用入口。
3. 执行过程入口。
4. 停止本轮在运行中和空闲时的状态。
5. 聊天输入、发送、Ctrl+Enter、空消息禁用状态。
6. 过程时间线展开、收起、参数/结果/依据查看。

### D. 项目应用

1. 总览、内容与数据、资料来源三个页签。
2. 打开应用、关闭应用视图、重新打开。
3. 展开/收起应用内容。
4. 应用内“打开浏览器”入口和返回工作台。
5. 已停止运行实例、已发布内容、嵌入视图状态的一致性。
6. 产物复核、接受、拒绝按钮的页面反馈（如当前项目存在可操作产物）。

### E. 管理入口

1. 系统配置/API Key 页面入口和返回。
2. 工具目录、工具安装/启用/禁用入口（只读查看或取消安装）。
3. Skills 目录、技能查看/启用入口（只读查看或取消）。
4. 运行设置、变量/提示词查看入口和返回。

## 通过标准

- 主要页面和按钮均能通过页面操作到达，或明确显示禁用原因。
- 可逆操作完成后能够回到原工作区，项目和会话轨迹不丢失。
- 菜单入口不能重复、不能打开空白页、不能出现无法返回的死路。
- 本轮发现的问题全部记录后再进入修复阶段。
